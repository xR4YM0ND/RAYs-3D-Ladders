This Resourcepack changes Block & Item model textures for Ladders in Minecraft.  
Support for LabPBR shaders since version 2.0

It doesn't add any items or blocks itself, it overwrites existing models / blockstates & textures from mods listed below & vanilla.

## Supported Mods:
</center>

- [Autumnity](https://modrinth.com/mod/autumnity) `// LabPBR`
